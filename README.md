# Library-Of-Babel-C
Library of Babel Coding in Language C

--------------------- Explication de ce qu'est la Bibliothèque de Babel ---------------------

La Bibliothèque de Babel est un espace fini rempli de toutes les combinaisons possibles de livres possibles avec les 26 lettres de l'alphabet (+ le point, la virgule, et l'espace)

--------------------- Composition de la Bibliothèque ---------------------

La Bibliothèque est composée d'hexagone
Chanque hexagone est composée de 5 étagères
Chaque étagère est composée de 32 livres
Chaque livre est composée de 410 pages
Chaque page de 40 lignes
Chaque ligne d'environ 80 caractères (chiffre exact dans ce code)
Cette bibliothèque n'est composé "que" de 6 hexagones mais cela est suffisant pour avoir 960 livres différents (soit 1 259 520 000 caractères placé de manière aléatoire)

--------------------- Programme et Utilisation ---------------------

Ce nombre élevé de caractère aléatoire à placer procure une certaine latence, je préviens, pouvant aller d'une trentaine de secondes à quelques minutes pour les PC les plus lents.)
Parcourir la bibliothèque demande d'entrer des touches et de valider l'entrée.
#####-----> Lancement du programme : copier l'adresse de l'exécutable (babel) dans le terminal et entrer.
